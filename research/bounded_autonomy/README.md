# DEX-COPY-AUTONOMY-001

## Purpose

Determine whether a human-governed, policy-constrained autonomous executor can
capture more **net follower value** than one-click or manual human execution
without creating unacceptable security, tail-loss, model or operational risk.

This is not a new source-wallet selection strategy. It is an additive execution
study attached to `WALLET-COPYABILITY-STUDY-001`.

## Core separation

```text
source-wallet skill
        !=
copyable signal value
        !=
execution-latency value
        !=
AI incremental value
```

The study estimates each layer separately. A source wallet can be profitable
while the follower, autonomous executor or AI layer is not.

## Initial venue and successor scope

The first empirical venue is Hyperliquid perpetuals because the parent study is
already preregistered there. BTC, ETH and SOL are the initial instruments.

Uniswap, PancakeSwap, Base/BSC token contracts, AMM price impact, MEV routing,
honeypot checks and smart-account modules are a separately gated EVM successor.
No result from Hyperliquid may be represented as proof for an AMM or memecoin
strategy.
