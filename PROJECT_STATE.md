## Exact current critical path

The active technical gate remains the capacity-safe, read-only Hyperliquid public
probe. The bounded-autonomy dossier does not jump that queue and does not open an
action endpoint.

1. Complete and attest the bounded read-only public technical probe.
2. Freeze exact output hashes, run/job/artifact identity and response-shape
   evidence.
3. Inventory official historical objects, schemas, gaps, retention and requester
   cost without opening an analytical partition.
4. Build and reconcile the deterministic wallet ledger.
5. Execute the point-in-time copyability study.
6. Only if follower alpha survives full costs may `DEX-COPY-AUTONOMY-001`
   progress from governance design to historical latency comparison.
7. Shadow, signed testnet and isolated live stages each require a separate,
   explicit governance decision and exact-head validation.

## Governance interpretation

`bounded_autonomy` means that the human pre-commits the capital, instruments,
venues, action types, model versions, limits and stop conditions. It does not
mean that an LLM receives a general-purpose wallet or exchange key.

The current repository remains credential-free and read-only. No file in this
dossier is an order, a recommendation to deploy capital, or evidence that the
strategy is profitable.
